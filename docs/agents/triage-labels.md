# Triage labels

The skills use five canonical triage roles. This file maps each role to this repository's GitHub label.

| Canonical role    | Tracker label     | Meaning                                       |
| ----------------- | ----------------- | --------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate this issue.      |
| `needs-info`      | `needs-info`      | Waiting on the reporter for more information. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent.       |
| `ready-for-human` | `ready-for-human` | Requires human implementation.                |
| `wontfix`         | `wontfix`         | Will not be actioned.                         |

When a skill mentions a canonical role, apply the corresponding tracker label.

## Additional workflow labels

| Tracker label | Meaning                                                |
| ------------- | ------------------------------------------------------ |
| `in-progress` | Work is committed on a branch that has not merged yet. |
